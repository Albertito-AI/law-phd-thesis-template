# Institutional profiles

The implemented Groningen layout is selected through `groningen.tex`. Its dimensions are in `lawthesis.cls`; its sourced requirements and limitations are in `docs/groningen.md`.

The generic profile is the default `main.tex`. It is adaptable to institutions internationally. It does not claim that one set of margins, section ordering or word-count rules applies everywhere.

Additional profiles should provide a dated primary-source record, a minimal compiling example and explicit limits. See `docs/customisation.md` before contributing one.
